生成日期：2026-05-20 | 状态：已完成

## 1. 工作概述

`off_design_eval.py`（~680行）是 Part III "Off-Design鲁棒性评估" 的核心脚本，完成以下全流程：

```
加载M3代表设计 → 固定9个设计参数 → 替换季节对边界条件(T_hs, T_cs)
→ CBSim非设计工况求解 → 计算性能保持率 R = f(off-design)/f(nominal)
→ 鲁棒性排序 → 可视化出图
```

**核心问题：** 在M3近优空间中选出的三个代表设计（D_eff / D_den / D_bal），在季节切换时谁最稳定？

**输入：** `results/near_optimal_{WP}_designs.csv`（由M3生成）  
**输出：** 每工况对3张图 + 2张CSV数据表

## 2. 使用方法

### 2.1 全部分析（3对季节对）

```bash
cd pure_deap_nsga
python3 off_design_eval.py
```

### 2.2 单季节对分析

```bash
python3 off_design_eval.py --pair DC-A_DC-B
python3 off_design_eval.py --pair DC-E_DC-F
```

### 2.3 含参数扫描（可选，§5.3）

```bash
python3 off_design_eval.py --sweep
```

> **注意：** CBSim 是设计点求解器，单独扰动一个参数容易破坏循环闭合，参数扫描的收敛率很低。论文 v3.0 将 §5.3 标记为可选章节。

### 2.4 参数说明

| 参数 | 含义 |
|------|------|
| `--pair` | 单季节对，格式 `冬季WP_夏季WP`，如 `DC-A_DC-B` |
| `--sweep` | 启用 real-choice 参数扫描（实验性） |

**不指定 `--pair` 时，默认运行全部3对：** (DC-A, DC-B), (DC-C, DC-D), (DC-E, DC-F)

## 3. 分析方法说明

### 3.1 季节对实验设计

数据中心自然存在的冬/夏冷源温差（冬季 T_cs=5°C, 夏季 T_cs=25°C）提供了理想的 off-design 实验设计：

| 季节对 | 冷却技术 | 冬季 ΔT | 夏季 ΔT | Δ(ΔT) |
|--------|---------|---------|---------|--------|
| DC-A→DC-B | 风冷 | 30K | 15K | -15K |
| DC-C→DC-D | 冷板液冷 | 45K | 30K | -15K |
| DC-E→DC-F | 高性能液冷 | 60K | 50K | -10K |

### 3.2 评估流程

对每个冬季工况的三个代表设计：

1. **名义评估：** 在设计工况的边界条件下运行 CBSim，得到名义性能 f_nom
2. **非设计评估：** 固定所有9个设计参数，仅替换为配对夏季工况的 T_hs 和 T_cs，得到 off-design 性能 f_off
3. **性能保持率：** R = f_off / f_nom × 100%（三个目标分别计算）
4. **对称性检验：** 同样评估夏季设计在冬季条件下的表现

### 3.3 收敛状态分类

CBSim 在非设计工况下可能出现三种状态：

| 状态 | 含义 | 论文解释 |
|------|------|---------|
| 收敛且 R ≈ 100% | 设计对该边界变化不敏感 | 鲁棒设计 |
| 收敛但 R << 100% | 性能显著退化 | 可接受退化 |
| 不收敛（循环不一致） | 设计在非设计工况下热力学不可行 | 脆弱设计 |

## 5. 核心发现

### 5.1 设计策略鲁棒性排序

| 设计策略 | 冬季→夏季收敛率 | η_p2p 保持率范围 | 结论 |
|---------|---------------|-----------------|------|
| **D_eff**（效率导向） | **3/3** | 63.5–68.5% | **唯一跨工况鲁棒策略** |
| D_bal（膝点折衷） | 1/3 | 59.9% | 仅低ΔT工况可用 |
| D_den（密度导向） | 0/3 | — | 系统性脆弱，不可用于非设计 |

### 5.2 不对称鲁棒性

**冬季→夏季：** 4/9 收敛（D_eff×3 + D_bal×1 DD-A）  
**夏季→冬季：** **0/9 收敛**

→ 夏季设计在冬季条件下完全不可行。**冬季应作为数据中心CB的设计基准。**

物理原因：冬季设计在大ΔT下运行，切换到夏季小ΔT时系统仍有热力学可行性；反向则要求系统在更恶劣的温差下运行，设计参数（特别是换热器温差配置）无法满足。

### 5.3 目标函数的非设计响应特征

| 目标 | 非设计响应 | 物理机制 |
|------|----------|---------|
| e_th | **完美保持 R=100%** | 储热密度仅取决于T_st_ht和dT_st_sp，与边界条件无关 |
| η_p2p | **适度退化 R=64–69%** | 工质运行点偏离最优，COP_HP和η_HE同时降低 |
| η_ex | **ΔT依赖** | DC-A→B: 提升至172%（ΔT减半降低不可逆性）; DC-E→F: 降至76%（ΔT相对降幅不足） |

### 5.4 边界限制

- **3/18 名义评估不收敛：** Pareto 边缘设计在 CBSim 重评估时存在数值敏感性（循环不一致），可能与 CSV 浮点精度截断或初始化工况细微差异有关。论文中应标注此限制。
- **§5.3 参数扫描不可行：** CBSim 是设计点求解器，单独扰动一个参数会破坏循环闭合。此节已在论文 v3.0 中标记为可选。

## 6. 与 Laterre 的对话定位

| 本文 §5 | Laterre 对应 | 关系 |
|---------|------------|------|
| Off-design 方法框架 | McTigue & Neises (2024) | 方法借鉴 |
| 季节对实验设计 | Laterre 2025 §3.4.2（提出但未完成） | **原创贡献** |
| D_eff 鲁棒性优势 | Laterre 2026 near-optimal design selection | **延伸验证** |

Laterre §3.4.2 提出 "容忍轻微性能退化可找到对参数偏差不敏感的构型"，但未完成分析。本文在数据中心场景下完成了该分析，并发现**效率导向设计（D_eff）恰好是鲁棒性最高的策略**——这是一个非平凡的结果，因为直觉上折衷设计（D_bal）可能更鲁棒。

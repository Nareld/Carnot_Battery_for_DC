# Archived Scripts

These scripts were exploratory or one-off and have been superseded by more general tools.

**Why archived:**
- `plot_global_pareto_DCB.py` through `DCE_DCF.py` — Per-WP global Pareto scripts, superseded by `build_global_pareto.py` which handles any WP generically.
- `plot_global_pareto_etaex.py`, `etaex_eth.py`, `etaex_eth_laterre.py` — DC-A exploratory plots, covered by `build_global_pareto.py` Interface I/II output.
- `plot_global_pareto_laterre.py` — Laterre-style replication attempt, exploratory.
- `build_presentation.py` — One-off group meeting PPT generator, not reusable.

If you need to recover code from these (e.g., a specific visualization trick), they remain here as reference. Do not import from them.
